How to get a FREE API Key (takes 2 minutes)
  1. Go to the Google Cloud Console.
  2. Create a new project (name it "YT Peek" or similar).
  3. Search for the YouTube Data API v3 in the library and click Enable.
  4. Go to Credentials, click + Create Credentials, and select API Key.
  5. Copy that API key, paste it in the box above, and click Save & Validate Key!
